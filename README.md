# QuickBite

Open `index.html` in a browser.

## How it works

- `index.html`: lists and searches restaurants.
- `restaurant.html`: shows a restaurant menu and adds items.
- `cart.html`: changes quantities and calculates the bill.
- `checkout.html`: validates delivery details and creates an order.
- `confirmation.html`: displays a simple tracking simulation.
- `orders.html`: displays saved orders.
- `app.js`: contains sample data and all behaviour.

The browser's `localStorage` saves the cart and order history, so refreshing does not erase them. To reset the demo, clear site data in the browser.
